# 大模型协作记录

本目录对应选题指南 3.3.5.3 的"大模型协作记录:提示词、模型回答、自我纠错轨迹、智能体工作流设计"。

| 文件 | 内容 |
|---|---|
| `collaboration_record.md` | 协作方式、关键提示词(用户原话)、模型的回答与决策、自我纠错轨迹、智能体工作流 |
| `raw/`(待放入) | **完整原始对话导出**。见下面的说明 |

## 必读:这份记录的来源与缺口
- 协作使用 Anthropic Claude(通过 claude.ai / Claude Code 会话)。当前这一阶段的会话配置为 `claude-sonnet-5-5`;更早阶段使用的型号以原始聊天记录为准。
- 这个会话因为内容过长被压缩过。压缩前的**逐字原始对话没有保存在本仓库可读取的文件里**。因此 `collaboration_record.md` 中:
  - 标注"用户原话"的是压缩摘要里逐字保留的用户消息;
  - 标注"回答要点""纠错"的是根据压缩摘要整理的**转述**,不是模型回答的逐字摘录,文中已逐条注明;
  - 标注"逐字"的少数回答来自本阶段仍在上下文中的原文。
- **请在提交前把完整的原始聊天导出放进 `raw/`**(例如从 claude.ai 的"设置 → 隐私 → 导出数据"得到的 `conversations.json`,或逐个对话另存为文本)。导出前请检查并删除其中不想公开的个人信息(邮箱、密码等)。评委要的是"提示词、模型回答与自我纠错轨迹",原始导出是最有力的证据。
