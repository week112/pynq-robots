# golden_compare

- **适用场景**:任何 PL/HLS 流式核与软件黄金参考的逐字节比对(缩放、色彩转换、滤波等),与题目无关。
- **使用方法**:`compare(hw_out, ref, name)` 返回不一致字节数、前几个位置和最大绝对差;自带 `box2x2_rgb()`(2×2 均值,`(sum+2)>>2`,BGR→RGB)作为示例参考。自测:`python3 golden_compare.py selftest`。
- **已验证效果**:自测中该参考与 OpenCV `INTER_AREA` 逐字节一致,人为改 1 个 LSB 能被检出(n=230400 中 1 处不一致)。本队 HLS 核 `preproc` 的 C 仿真(57600 个输出字、0 字节不一致、TLAST 位置正确)和板上 DMA 往返比对均采用同样的方法。
- **失效条件**:要求输出与参考位宽、排布(字节序、通道序)一致;对浮点结果请改用容差比较。
- **提炼来源**:HLS 核最初只"看起来对",补做逐字节比对后才能在报告中断言"与 INTER_AREA 一致"。
