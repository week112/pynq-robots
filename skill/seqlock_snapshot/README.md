# seqlock_snapshot

- **适用场景**:PL 自由运行、PS 通过多个 AXI 寄存器读取同一时刻的一组数据(如 IMU 偏航角 + 时间戳 + 状态),不想为此加握手的场合。
- **使用方法**:PL 侧参照 `snippet.v`,在同一时钟周期提交全部数据并令序号加 1;PS 侧调用 `read_snapshot(seq_fn, data_fns)`:读序号→读数据→再读序号,两次相同才接受。自测:`python3 selftest.py`。
- **已验证效果**:自测中模拟 PL 高速更新、读者被打断,朴素读取 299/300 次出现"半新半旧",seqlock 接受的 86 次快照中 0 次撕裂。本队 `car_pl.py` 的 `Car.snap()` 即用此法读取(序号、时间戳、偏航角来自同一样本),实板中 PL 时间戳相邻间隔 1497 个样本全为 2000 µs。
- **失效条件**:要求 PL 确实在同一周期提交数据与序号;序号位宽太小且读者被阻塞过久时,序号回绕可能误判(16 位下需阻塞 >65535 个样本周期,实际不会发生)。读者持续被更新打断时 `read_snapshot` 会抛异常而不是返回脏数据。
- **提炼来源**:需要把 PL 时间戳与摄像头帧对齐、又要保证角度与时间戳属于同一样本。
