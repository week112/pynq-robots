# 04 报告只用数据文件里的数字

**提示词模板**

```
我给你原始 csv 和日志。请:
1. 用脚本(不要心算)算出 P50/P95/P99/max、样本数,并说明每个统计排除了哪些样本;
2. 写报告段落时,每个数字后注明来自哪个文件;
3. 没有数据的指标写"待补",不要估计;推算值必须标注"推算"。
```

- **适用场景**:性能数据汇总、设计报告撰写。
- **已验证效果**:`data/analyze.py` 复算出报告全部关键数字(端到端延迟 n=253、推理 n=271、转向 23 次等)。过程中发现并更正了一处口径:水瓶试验里**真正由水瓶触发的转向只有 2 次**,其余由盆栽/椅子/人触发,因此水瓶成功率表保留为"待补"而不是用现有数据凑数。吞吐 3.4 Mbit/s 在报告中明确标注为"由帧大小与帧率推算,未实测"。
- **失效条件**:模型会倾向于把"看起来合理"的数填进去,必须在提示词里禁止并抽查。
- **来源**:设计报告撰写与数据复核。
