# 02 先写软件镜像与测试平台,再上 Vivado

**提示词模板**

```
请为 <模块功能> 写三样东西:
(a) Verilog 模块(参数化,时钟 <MHz>);
(b) 一个周期级的 Python 镜像模型(同一状态机、同一定点运算),带一个行为级的外设模型(如 I²C 从机);
(c) Verilog 测试平台,检查 <寄存器初始化序列/占空比/看门狗/时间戳间隔>,打印 PASS/FAIL。
先运行 (b),把协议、序号、缩放类错误在软件里改掉,再给我 (a)(c)。
```

- **适用场景**:RTL 状态机、串行总线控制器、带定点运算的采集核。
- **已验证效果**:`sim/rtl/mirror.py` 能在无 Vivado 的环境里复现 `imu_reader` 的初始化寄存器序列(6B/1A/19/1B/1C)、14 次提交、时间戳每次 +2000 µs;`sim/run_sim.sh` 一条命令复跑。**但它不能替代上板**:这个镜像没有发现"三态信号没映射到引脚"的问题(见 `../pitfalls.md` 第 2 条)。
- **失效条件**:镜像与 RTL 是两份实现,可能同时错;三态、时钟域、约束类问题必须上板验证。
- **来源**:IMU 读取核的开发过程。
