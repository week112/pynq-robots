# pynq_safe_overlay

- **适用场景**:任何用 Jupyter 反复运行 Overlay 加载单元、且有线程(心跳/轮询)访问 AXI 寄存器的 PYNQ 工程(与题目、板卡无关)。
- **使用方法**:`load_overlay_once(bit)` 代替 `Overlay(bit)`;`replace_active("app", App(ol))` 创建对象前自动关闭旧对象。离板自测:`python3 selftest.py`。
- **已验证效果**:本队小车在同一内核里重复运行加载比特流的单元,100% 掉线(板子 ping 不通,必须断电)。加入"同一比特流只加载一次 + 先停旧线程"后,重复运行不再掉线(开发者实板反馈"没有掉线,稳定了";未做长时统计)。离板自测验证了"相同比特流不重复下载、旧实例先关闭"的逻辑。
- **失效条件**:只在 `PL.bitfile_name` 能读到当前比特流时才会跳过下载;换了板卡镜像、或旧对象没有 `close()`,则需自行补充。它不能解决供电不足、摄像头 USB 掉电等硬件原因。
- **提炼来源**:开发板反复掉线的排查过程(先后怀疑供电、摄像头,最终由"每次运行前重启内核就不掉线"这一对照定位到根因),见 `../pitfalls.md` 第 1 条。
